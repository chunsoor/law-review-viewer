# 검토 데이터(JSON) 구조

뷰어는 이 JSON 하나로 움직인다. 화면 코드에는 사건에 관한 내용이 전혀 없다.

## 최상위

| 키 | 필수 | 설명 |
|---|---|---|
| `meta` | ● | 검토서 머리말 |
| `laws` | ● | 인용한 법령 목록. 근거마다 여기의 `id`를 참조한다 |
| `parties` | ● | 처분 대상(기사·회사·시 등). 필터와 합계 단위 |
| `kinds` | ● | 처분 종류(과태료·과징금 등). 필터와 색상 |
| `cols` | ● | 근거 사슬 단계의 기본 이름 4종 |
| `issues` | ● | 검토 항목 배열 |

## meta

```json
"meta": {
  "title": "시내버스 하차 중 사고 행정처분 법률검토",
  "subtitle": "2026. 9. 7. 제천운수(주) 충북72자2308 하차 중 사고",
  "org": "제천시 교통과",
  "reviewedAt": "2026. 9. 19.",
  "basis": "위반행위일(2026. 9. 7.) 당시 시행 중이던 법령",
  "status": "검토본",
  "headline": "운전기사 과태료 70만원, 운송사업자 과징금ㆍ과태료 550만원 부과가 가능합니다.",
  "disclaimer": "내부 검토용입니다. 확정 금액은 의견제출 절차를 거친 뒤 결정됩니다."
}
```

`headline`은 첫 화면 검은 띠에 그대로 나간다. **결론 한 문장**이어야 한다.
`basis`는 어느 시점 법령을 적용했는지 한 줄로 밝힌다.

## laws

```json
{"id":"act","name":"여객자동차 운수사업법","sh":"법","no":"법률 제21710호","eff":"2026. 7. 1."}
```

`eff`가 `"현행"`이면 출처 표시에서 `[시행 …]`을 생략한다. 시행일을 아는 법령은 반드시 적는다.

## parties / kinds

```json
"parties":[{"id":"driver","label":"운전기사"},{"id":"company","label":"운송사업자"}],
"kinds":[{"id":"fine","label":"과태료","color":"red"},{"id":"charge","label":"과징금","color":"orange"},
         {"id":"order","label":"개선명령","color":"green"}]
```

`color`는 `red` / `orange` / `green` / `gray` 넷 중 하나. 결론 금액 글자색에만 쓴다.

## cols

```json
"cols": {
  "law":"법률 — 무엇이 금지ㆍ의무인가",
  "spec":"시행령ㆍ규칙 — 어떻게 구체화되나",
  "rule":"처분기준 — 얼마인가",
  "check":"예외ㆍ겹침 확인"
}
```

단계마다 `title`을 따로 주면 그 이름이 우선한다(권한·절차처럼 성격이 다른 항목에 쓴다).

## issues[]

| 키 | 필수 | 설명 |
|---|---|---|
| `id` | ● | 내부 식별자(`i1`, `a1` …) |
| `seq` | ● | 화면에 찍히는 번호. `①`, `권한`, `절차` 처럼 문자열 |
| `party` / `kind` | ● | parties / kinds의 id |
| `title` | ● | 쟁점 이름 (한 줄) |
| `question` | ● | 이 항목이 답하는 질문 한 문장 |
| `amount` | ● | 합계에 더할 금액(원). 금액이 없으면 `0` |
| `display` | ● | 화면에 찍히는 결론 문자열(`"10만원"`, `"명령 가능"`, `"해당 없음"`) |
| `certainty` | ● | `확정` / `조건부` / `대체` / `해당 없음`. `확정`·`해당 없음` 외에는 "추가 확인 필요" 건수에 잡힌다 |
| `sum` | ● | `true`면 합계에 더한다. 다른 항목에 흡수되거나 부과하지 않는 항목은 `false` |
| `note` | | 단서 한 줄. 합산에서 뺀 이유는 여기에 적는다 |
| `conds` | | 확인이 필요한 사실 배열 |
| `change` | | 이전 검토와 달라진 금액 `{"before","after","why"}` |
| `steps` | ● | 근거 사슬 |

## steps[]

```json
{
  "col": "rule",
  "title": "처분기준 — 얼마인가",
  "arrow": "위반하면 얼마인지는 시행령 별표 6에 있다",
  "gist": "명단에 있는 준수사항은 50만원, 그 밖은 10만원이다.",
  "note": "표기가 어긋나는 이유 등 주석",
  "refs": []
}
```

- `arrow` — **앞 단계에서 이 단계로 넘어가는 이유**. 단계 사이 회색 줄로 나온다. 첫 단계에는 쓰지 않는다.
- `gist` — 그 단계가 말하는 바를 **쉬운 말 한 문장**으로. 법령 용어(호·목)를 쓰지 않는다.
- `note` — 해석상 주의점. 단계 맨 아래 작은 글씨.

## refs[] — 조문 인용 (두 가지 형태)

**산문형** (조문 본문)

```json
{
  "label": "법 제26조제1항제9호",
  "law": "act",
  "ps": ["제26조(운수종사자의 준수 사항)",
         "① 운수종사자는 … 하여서는 아니 된다. <개정 2013.3.23>",
         "9. 그 밖에 … 국토교통부령으로 정하는 사항을 위반하는 행위"],
  "hl": ["하여서는 아니 된다"],
  "note": ""
}
```

- `ps` 한 칸이 화면의 한 문단이다. 조문 제목 → 항 → 호 → 목 순으로 넣는다.
- `hl` 문구는 **본문에 글자 그대로 있어야** 형광이 칠해진다(build.py가 확인해 준다).
- `<개정 …>` `<신설 …>`은 화면에서 자동으로 흐리게 처리된다. 지우지 말고 그대로 둔다.

**표형** (별표)

```json
{
  "label": "[별표 6] 제2호 버목",
  "law": "b6",
  "cap": "버. 법 제26조제1항제9호를 위반한 경우",
  "cols": ["위반행위","근거 법조문","1회","2회","3회 이상"],
  "rows": [["1) … 국토교통부령으로 정하는 준수사항을 위반한 경우","법 제94조제3항제4호","50","50","50"],
           ["2) 1)에 따른 준수사항 외의 준수사항을 위반한 경우","법 제94조제3항제4호","10","10","10"]],
  "hlrow": [1],
  "note": "단위: 만원"
}
```

- `cap` — 표 위에 붙는 모(母) 항목 문장.
- `hlrow` — 이 건에 해당하는 행 번호(0부터). 그 행만 노랗게 칠해진다.
- 세 번째 칸부터는 가운데 정렬·숫자 글꼴이 적용된다.
- `note`가 `단위`로 시작하면 "확인 ·" 머리말 없이 그대로 나온다.
- 열이 아주 많은 별표(과징금 표 등)는 **이 건에 해당하는 열만 발췌**하고 `note`에 "○○ 열 발췌"라고 밝힌다.

## 최소 예시

```json
{
 "meta":{"title":"○○ 검토","subtitle":"","org":"제천시 교통과","reviewedAt":"2026. 1. 1.",
         "basis":"현행 법령","status":"검토본","headline":"결론 한 줄","disclaimer":"내부 검토용"},
 "laws":[{"id":"act","name":"○○법","sh":"법","no":"","eff":"현행"}],
 "parties":[{"id":"p1","label":"신청인"}],
 "kinds":[{"id":"k1","label":"허가","color":"green"}],
 "cols":{"law":"법률","spec":"시행령ㆍ규칙","rule":"기준","check":"예외 확인"},
 "issues":[{"id":"i1","seq":"①","party":"p1","kind":"k1","title":"쟁점","question":"가능한가",
   "amount":0,"display":"가능","certainty":"확정","sum":false,"note":"","conds":[],
   "steps":[{"col":"law","gist":"쉬운 말 한 줄","refs":[
     {"label":"법 제1조","law":"act","ps":["제1조(목적) …"],"hl":[]}]}]}]
}
```
