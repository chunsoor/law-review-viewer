# 조문 원문을 정확히 가져오는 법

이 뷰어의 값어치는 **인용이 틀리지 않는 것**에 있다. 아래 순서를 지킨다.

## 1. 기준 시점을 먼저 정한다

행정처분·과태료는 **위반행위 당시** 법령이 기준이다.

- 행정기본법 제14조제3항 — 제재처분은 위반행위 당시 법령. 다만 뒤에 기준이 가벼워졌으면 가벼운 쪽.
- 질서위반행위규제법 제3조 — 과태료도 행위 시 법률, 가벼워졌으면 가벼운 쪽.

기준일을 `meta.basis`에 적고, 절차 항목 첫 단계에 위 두 조문을 인용해 둔다.

## 2. 시행일 함정 (반드시 확인)

`mcp__law__law_body`는 **현행이 아니라 시행예정 판본**을 돌려줄 때가 있다.

1. 응답의 `기본정보.시행일자`를 본다.
2. 조문마다 붙은 `조문시행일자`도 본다. 조문별로 다를 수 있다.
3. 둘 중 하나라도 기준일보다 뒤면 그 본문을 쓰면 안 된다. 국가법령정보센터에서 기준일 시행본 PDF(머리글 `[시행 YYYY. M. D.]`)를 받아 대조한다.
4. 시행령·시행규칙도 같은 방식으로 각각 확인한다.

과거에 이 확인을 건너뛰어, 맞는 인용을 틀렸다고 판단했다가 철회한 적이 있다.

## 3. 조문 본문 — XML이 가장 깨끗하다

국가법령정보센터 XML(`<조문단위>` / `<항>` / `<호>` / `<목>`)을 파싱하면 줄바꿈 없는 문장 그대로 나온다. 다음 구조를 쓴다.

```
조문단위 → 조문번호 / 조문제목 / 조문시행일자 / 조문내용
          → 항 (항번호, 항내용)
            → 호 (호번호, 호내용)
              → 목 (목번호, 목내용)
```

`ps`에는 `조문내용`(제목 줄) → 해당 `항내용` → 해당 `호내용` 순으로 담는다. 필요한 호만 넣고 나머지는 빼도 된다.

**PDF에서 글자를 긁는 방식은 피한다.** 국가법령정보센터 PDF는 글자 단위로 줄을 바꿔서, 줄을 이으면 띄어쓰기가 사라진다(`50만원` + `이하의` → `50만원이하의`). 부득이 PDF를 쓸 때는 줄 단위로 그대로 두거나, 띄어쓰기를 사람이 확인한다.

## 4. 별표 — 표는 손으로 옮기고 그림으로 대조한다

별표는 표라서 자동 추출이 잘 깨진다.

- 한글 파일(HWP/HWPX)을 문단 목록으로 풀면 **셀이 문단 하나씩** 나온다. 행 제목 다음에 근거 법조문, 그다음에 금액이 차례로 온다.
- **병합된 셀 함정**: 모(母) 항목 아래 1)·2)가 있으면 금액이 한 칸 안에 여러 줄로 들어간다. 이때 숫자의 **세로 위치로 판단하면 안 된다**. 숫자 줄은 위에서부터 1), 2) 순서로 대응한다. 반드시 PDF를 그림으로 렌더해 눈으로 한 번 더 맞춘다.
- 과징금 별표처럼 차종 열이 10개 가까운 표는 **해당 열만 발췌**하고 `note`에 "○○ 열 발췌"라고 밝힌다.
- 원문에 오타가 있어도 고치지 말고 그대로 옮긴 뒤 `note`에 "원문 표기"라고 적는다.

## 5. 자치법규

`mcp__law__ordin_search`로 조례·규칙을 찾고, 위임 별표는 자치법규정보시스템에서 HWPX를 받아 본문을 확인한다. 공포번호(예: 규칙 제3128호)를 `laws[].no`에 적는다.

## 6. 인용 전 자체 점검

- [ ] 인용한 조문이 기준일에 시행 중이었나 (`조문시행일자` 확인)
- [ ] 금액·기간이 별표 원문과 같은가 (그림으로 대조)
- [ ] 위임 사슬이 끊기지 않는가 (법 → 위임 조문 → 하위법령 → 별표)
- [ ] 처분기준이 사업정지가 아닌데 과징금으로 갈음하고 있지 않은가
- [ ] 겹치는 위반이 있을 때 합산인지 흡수인지 밝혔는가
- [ ] 권한 위임 경로가 이 사업 종류에 실제로 미치는가 (단서·제외 규정 확인)
